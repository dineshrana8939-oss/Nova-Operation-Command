# Prebuilt race tracks

Track data in this folder is copied unchanged from the public collection
**Dking07/fivem-tracks** (https://github.com/Dking07/fivem-tracks).
That repository ships an empty LICENSE file, so no licence terms are stated —
keep this credit with the data, do not redistribute it as your own, and check
with the author before publishing this resource anywhere public.

On resource start each track is added once to Saved Routes as a Gang Rally
template named "[Prebuilt] <category> - <name>" (see saved_routes.lua).
